Graus de Liberdade e Discretização Espacial:

O pórtico plano é discretizado em 5 nós e 4 elementos de barra. Cada nó $i$ possui 3 graus de liberdade (GDLs) no sistema global: translação horizontal ($u_i$ na direção global X), translação vertical ($v_i$ na direção global Y) e rotação ($\theta_i$ no sentido anti-horário). A numeração dos GDLs para o nó $i$ segue a ordem $[3i-2, 3i-1, 3i]$. O sistema global possui, portanto, 15 GDLs no total.

Explicação do cálculo da conectividade:
Para cada elemento conectando o nó inicial $I(X_i, Y_i)$ ao nó final $F(X_f, Y_f)$, o comprimento $l$ é calculado por: $$l = \sqrt{\Delta X^2 + \Delta Y^2}$$ Os cossenos e senos diretores ($\cos\beta$ e $\sin\beta$), necessários para rotacionar as propriedades locais para os eixos globais, são dados por: $$\cos\beta = \frac{\Delta X}{l} = \frac{X_f - X_i}{l}, \quad \sin\beta = \frac{\Delta Y}{l} = \frac{Y_f - Y_i}{l}$$
