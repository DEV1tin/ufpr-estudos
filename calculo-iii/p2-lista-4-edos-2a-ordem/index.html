Tópico 1: Verificação de Soluções, P.V.I., P.V.C. e Existência/Unicidade (T.E.U.)

🧠 O que você precisa lembrar dos Cálculos Anteriores (Pré-Requisitos)

  • 1. Regra do Tombo (Derivada de Polinômios - Cálculo 1): Para derivar \(x^n\), "tombamos" o expoente multiplicando e subtraímos 1: \(\frac{d}{dx}(x^n) = n \cdot x^{n-1}\). A derivada de uma constante sozinha (ex: \(3\) ou \(-5\)) é sempre \(0\).
  • 2. Derivada da Exponencial com Regra da Cadeia (Cálculo 1): A derivada de \(e^x\) é o próprio \(e^x\). Porém, quando há um número multiplicando o \(x\) no expoente, como \(e^{kx}\), a Regra da Cadeia obriga a multiplicar pela derivada do expoente \((kx)' = k\): \[\frac{d}{dx}\left(e^{kx}\right) = k \cdot e^{kx} \quad \text{e derivando de novo:} \quad \frac{d^2}{dx^2}\left(e^{kx}\right) = k^2 \cdot e^{kx}\] Exemplo: Se \(y = e^{-2x}\), então \(y' = -2e^{-2x}\) e \(y'' = (-2)\cdot(-2)e^{-2x} = 4e^{-2x}\).
  • 3. Restrições de Domínio e Continuidade (Pré-Cálculo / Cálculo 1): Uma função elementar é contínua em todos os números reais, exceto onde ocorrem 3 proibições clássicas da matemática:
    1. Divisão por zero: Em \(\frac{A(t)}{B(t)}\), o denominador nunca pode zerar \(\implies B(t) \neq 0\).
    2. Logaritmo de número zero ou negativo: Em \(\ln(\text{algo})\), o interior deve ser estritamente positivo \(\implies \text{algo} > 0\) (note que em \(\ln(|t+1|)\), o módulo já deixa positivo, exceto quando \(t+1 = 0 \implies t \neq -1\)).
    3. Raiz de índice par de número negativo: Em \(\sqrt{\text{algo}}\), o interior não pode ser negativo \(\implies \text{algo} \ge 0\).

📘 Introdução ao Tema: EDO Linear de 2ª Ordem e o T.E.U.

Uma Equação Diferencial Ordinária (EDO) de 2ª Ordem Linear é toda equação que relaciona uma função desconhecida \(y(t)\), sua primeira derivada \(y'(t)\) e sua segunda derivada \(y''(t)\) de forma linear (sem expoentes como \((y')^2\) ou produtos \(y \cdot y'\)):

\[a_2(t) y''(t) + a_1(t) y'(t) + a_0(t) y(t) = g(t)\]

Dividindo toda a equação pelo coeficiente líder \(a_2(t)\), obtemos a chamada Forma Padrão (ou Forma Canônica):

\[y''(t) + p(t) y'(t) + q(t) y(t) = f(t)\]
  • Como verificar se uma função é solução? Basta calcular as derivadas \(y'\) e \(y''\) da função dada, substituir na EDO e checar se os dois lados da igualdade ficam idênticos.
  • P.V.I. (Problema de Valor Inicial): Dá a EDO junto com o valor da função \(y(t_0) = y_0\) e da derivada \(y'(t_0) = z_0\) no mesmo ponto inicial \(t_0\).
  • P.V.C. (Problema de Valor de Contorno): Dá a EDO junto com condições da função em dois pontos diferentes do intervalo: \(y(a) = y_0\) e \(y(b) = y_1\).

📖 Exercício 1 — Verificação de P.V.I. e P.V.C.
Introdutório ao Tema
🔍 Raio-X: Como Interpretar e Enxergar na Prova

O comando testa se você diferencia P.V.I. (condições de \(y\) e \(y'\) no mesmo ponto \(x_0\)) de P.V.C. (condições em dois extremos \(a, b\)) e sabe substituir as derivadas na EDO sem errar a Regra da Cadeia.

1. (a) Verifique que a função \(y(x) = e^{2x} + e^{-2x}\) é solução do problema de valor inicial: \(y''(x) - 4y(x) = 0, \quad y(0) = 2, \quad y'(0) = 0\).
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(y(x) = e^{2x} + e^{-2x}\) // Escrevemos a função candidata que queremos testar.
02 \(y'(x) = 2e^{2x} - 2e^{-2x}\) // Calculamos a 1ª derivada pela Regra da Cadeia: (e2x)' = 2e2x e (e-2x)' = -2e-2x.
03 \(y''(x) = 4e^{2x} + 4e^{-2x}\) // Calculamos a 2ª derivada derivando y'(x): 2·(2e2x) - 2·(-2e-2x) = 4e2x + 4e-2x.
04 \(y''(x) - 4y(x) = (4e^{2x} + 4e^{-2x}) - 4(e^{2x} + e^{-2x})\) // Substituímos y''(x) e y(x) no lado esquerdo da EDO dada.
05 \(y''(x) - 4y(x) = 4e^{2x} + 4e^{-2x} - 4e^{2x} - 4e^{-2x} = 0\) // Distribuímos o -4 e cancelamos os termos opostos. Deu 0 = 0! Logo, satisfaz a EDO.
06 \(y(0) = e^{2\cdot 0} + e^{-2\cdot 0} = e^0 + e^0 = 1 + 1 = 2 \quad (\text{OK!})\) // Testamos a 1ª condição inicial trocando x por 0 em y(x). Lembre-se que todo número elevado a 0 vale 1.
07 \(y'(0) = 2e^{2\cdot 0} - 2e^{-2\cdot 0} = 2(1) - 2(1) = 0 \quad (\text{OK!})\) // Testamos a 2ª condição inicial trocando x por 0 na derivada y'(x). Todas as condições foram satisfeitas!
✓ Conclusão 1(a): Como \(y''(x) - 4y(x) = 0\), \(y(0) = 2\) e \(y'(0) = 0\), fica verificado que \(y(x) = e^{2x} + e^{-2x}\) é solução do P.V.I.
1. (b) Verifique que no intervalo \((0, \infty)\), a função \(y(x) = 3x^2 - 6x + 3\) satisfaz o problema de valor de contorno: \(x^2 y'' - 2xy' + 2y = 6, \quad y(1) = 0, \quad y(2) = 3\).
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(y(x) = 3x^2 - 6x + 3\) // Escrevemos a função polinomial fornecida no enunciado.
02 \(y'(x) = 6x - 6\) // Derivamos usando a Regra do Tombo: (3x2)' = 6x, (-6x)' = -6 e (3)' = 0.
03 \(y''(x) = 6\) // Derivamos novamente para achar a 2ª derivada: (6x)' = 6 e (-6)' = 0.
04 \(x^2 y'' - 2xy' + 2y = x^2(6) - 2x(6x - 6) + 2(3x^2 - 6x + 3)\) // Substituímos y, y' e y'' no lado esquerdo da EDO.
05 \(= 6x^2 - 12x^2 + 12x + 6x^2 - 12x + 6\) // Aplicamos a propriedade distributiva (chuveirinho) em cada parêntese.
06 \(= (6 - 12 + 6)x^2 + (12 - 12)x + 6 = 0x^2 + 0x + 6 = 6 \quad (\text{OK!})\) // Agrupamos os termos semelhantes de x2 e de x. Sobrou exatamente 6, igual ao lado direito da EDO!
07 \(y(1) = 3(1)^2 - 6(1) + 3 = 3 - 6 + 3 = 0 \quad (\text{OK!})\) // Verificamos a 1ª condição de contorno substituindo x = 1 na função original y(x).
08 \(y(2) = 3(2)^2 - 6(2) + 3 = 3(4) - 12 + 3 = 12 - 12 + 3 = 3 \quad (\text{OK!})\) // Verificamos a 2ª condição de contorno substituindo x = 2 em y(x).
✓ Conclusão 1(b): A função satisfaz a equação diferencial e ambas as condições de contorno em \(x=1\) e \(x=2\).

Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(y(x) = 3e^{2x} + e^{-2x} - 3x\) // Função dada para testarmos no P.V.I.
02 \(y'(x) = 6e^{2x} - 2e^{-2x} - 3\) // 1ª derivada: (3e2x)' = 6e2x, (e-2x)' = -2e-2x e (-3x)' = -3.
03 \(y''(x) = 12e^{2x} + 4e^{-2x}\) // 2ª derivada: (6e2x)' = 12e2x, (-2e-2x)' = +4e-2x e (-3)' = 0.

05 \(= 12e^{2x} + 4e^{-2x} - 12e^{2x} - 4e^{-2x} + 12x = 12x \quad (\text{OK!})\) // Cancelamos as exponenciais opostas e sobra 12x, que bate exatamente com o lado direito da EDO!

07 \(y'(0) = 6e^0 - 2e^0 - 3 = 6(1) - 2(1) - 3 = 6 - 5 = 1 \quad (\text{OK!})\) // Testamos a condição inicial de derivada em x = 0. Fica provado que é solução do P.V.I.

09 \(p(x), q(x), f(x) \text{ são contínuas em } I = \mathbb{R} = (-\infty, +\infty)\) // Funções constantes (0 e -4) e polinomiais (12x) são contínuas em toda a reta real, que contém x0 = 0.
✓ Conclusão 2: Sim, a solução é única em todo \(\mathbb{R}\), pois a EDO está na forma padrão e os coeficientes \(p(x)=0\), \(q(x)=-4\) e \(f(x)=12x\) são contínuos em toda a reta real \((-\infty, \infty)\), satisfazendo as hipóteses do Teorema de Existência e Unicidade (T.E.U.).

Tópico 2: Independência Linear (L.I.), Wronskiano e Superposição

Exercícios 4, 5, 6, 7, 8 e 9

🧠 O que você precisa lembrar dos Cálculos e Álgebra Linear (Pré-Requisitos)

  • 1. Determinante de Matriz \(2 \times 2\) (Álgebra Linear): Multiplica-se a diagonal principal menos a diagonal secundária: \[\begin{vmatrix} a & b \\ c & d \end{vmatrix} = a \cdot d - b \cdot c\]
  • 2. Regra do Produto para Derivadas (Cálculo 1): Quando temos uma multiplicação de duas funções de \(x\), como \(u(x) \cdot v(x)\), a derivada NÃO é \(u' \cdot v'\). A regra correta é: "derivada da primeira vezes a segunda, mais a primeira vezes a derivada da segunda": \[(u \cdot v)' = u' \cdot v + u \cdot v'\] Exemplo muito usado: Para derivar \(x e^{kx}\), fazemos \((x)' e^{kx} + x (e^{kx})' = 1\cdot e^{kx} + x \cdot k e^{kx} = (1 + kx)e^{kx}\).
  • 3. Derivada de Seno e Cosseno com Regra da Cadeia (Cálculo 1): \[(\cos(\beta x))' = -\beta \sin(\beta x) \quad \text{e} \quad (\sin(\beta x))' = \beta \cos(\beta x)\]
  • 4. Identidade Trigonométrica Fundamental: Para qualquer ângulo \(\theta\), vale sempre: \(\cos^2(\theta) + \sin^2(\theta) = 1\).
  • 5. Definição de Módulo \(|x|\) (Pré-Cálculo): O módulo abre em duas sentenças dependendo do sinal de \(x\): \[|x| = \begin{cases} x, & \text{se } x \ge 0 \\ -x, & \text{se } x < 0 \end{cases}\]

📘 Introdução ao Tema: L.I., Wronskiano e Conjunto Fundamental

  • Definição de Independência Linear (L.I.): Duas funções \(f_1(x)\) e \(f_2(x)\) são L.I. em um intervalo \(I\) se a única forma de a combinação linear \(c_1 f_1(x) + c_2 f_2(x) = 0\) valer para todo \(x \in I\) for tomando \(c_1 = 0\) e \(c_2 = 0\).
    Dica Prática: Para duas funções, elas são L.D. (Linearmente Dependentes) se e somente se uma é múltiplo constante da outra (\(\frac{f_2(x)}{f_1(x)} = \text{constante}\)). Se a divisão \(\frac{f_2(x)}{f_1(x)}\) depender de \(x\), elas são L.I.!
  • O Determinante Wronskiano \(W(f_1, f_2)\): Colocamos as funções na 1ª linha e suas derivadas na 2ª linha: \[W(f_1, f_2)(x) = \begin{vmatrix} f_1(x) & f_2(x) \\ f_1'(x) & f_2'(x) \end{vmatrix} = f_1(x) f_2'(x) - f_2(x) f_1'(x)\] Teorema: Se existir pelo menos um ponto \(x_0 \in I\) onde \(W(f_1, f_2)(x_0) \neq 0\), então \(f_1\) e \(f_2\) são Linearmente Independentes (L.I.) em \(I\).
  • Conjunto Fundamental de Soluções: Um par \(\{y_1, y_2\}\) forma um Conjunto Fundamental de uma EDO linear homogênea de 2ª ordem se: (1) ambas satisfazem a EDO, e (2) elas são L.I. (\(W \neq 0\)). Nesse caso, a Solução Geral é \(y(x) = c_1 y_1(x) + c_2 y_2(x)\).
📖 Exercício 4 — Independência Linear pela Definição
Introdutório ao Tema

5. Mostre que as funções \(y_1(x) = x^{-1}\) e \(y_2(x) = x^{1/2}\) formam um conjunto fundamental de soluções da equação diferencial \(2x^2 y'' + 3xy' - y = 0\) (para \(x > 0\)). [Deve verificar que satisfazem a E.D.O. e que são L.I.]

01 \(y_1(x) = x^{-1} \implies y_1'(x) = -x^{-2} \implies y_1''(x) = 2x^{-3}\) // ETAPA 1 (Testar y1): Derivamos y1 duas vezes pela Regra do Tombo: (-1)x-2 e (-1)(-2)x-3 = 2x-3.
02 \(2x^2(2x^{-3}) + 3x(-x^{-2}) - (x^{-1}) = 4x^{-1} - 3x^{-1} - x^{-1} = 0 \quad (\text{OK!})\) // Substituímos na EDO (lembrando que x2 · x-3 = x2-3 = x-1). Deu 0, logo y1 é solução!

⭐ Exercício 6 — O Caso Clássico de Wronskiano Nulo com Funções L.I.
Formato Provável de Prova
🔍 Raio-X: Como Interpretar e Enxergar na Prova

Pegadinha teórica clássica! Duas funções podem ser L.I. no intervalo inteiro e mesmo assim ter \(W(x) \equiv 0\) se NÃO forem soluções de uma mesma EDO linear com coeficientes contínuos (o que ocorre em \(x=0\) para \(x^2\) e \(x|x|\)).

6. (a) Mostre que para as funções \(f_1(x) = x^2\) e \(f_2(x) = x|x|\) o Wronskiano é sempre nulo em \(\mathbb{R}\).
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(f_2(x) = x|x| = \begin{cases} x\cdot x = x^2, & \text{se } x \ge 0 \\ x\cdot(-x) = -x^2, & \text{se } x < 0 \end{cases}\) // Abrimos a função módulo |x| em dois casos: para x positivo/zero (|x|=x) e para x negativo (|x|=-x).
02 \(\text{Caso 1 } (x \ge 0): \;\; f_1(x) = x^2 \implies f_1'(x) = 2x; \quad f_2(x) = x^2 \implies f_2'(x) = 2x\) // Calculamos as derivadas no semieixo positivo x ≥ 0.
03 \(W(x) = \begin{vmatrix} x^2 & x^2 \\ 2x & 2x \end{vmatrix} = x^2(2x) - x^2(2x) = 2x^3 - 2x^3 = 0 \quad (\text{para } x \ge 0)\) // Calculamos o Wronskiano para x ≥ 0. Deu zero idêntico!
04 \(\text{Caso 2 } (x < 0): \;\; f_1(x) = x^2 \implies f_1'(x) = 2x; \quad f_2(x) = -x^2 \implies f_2'(x) = -2x\) // Calculamos agora as derivadas no semieixo negativo x < 0.
05 \(W(x) = \begin{vmatrix} x^2 & -x^2 \\ 2x & -2x \end{vmatrix} = x^2(-2x) - (-x^2)(2x) = -2x^3 + 2x^3 = 0 \quad (\text{para } x < 0)\) // Calculamos o Wronskiano para x < 0. Também deu zero! Logo, W(x) = 0 para todo x real.
6. (b) Represente graficamente estas funções e mostre que elas são linearmente independentes em \(\mathbb{R}\).
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(c_1 f_1(x) + c_2 f_2(x) = 0 \implies c_1 x^2 + c_2 x|x| = 0, \quad \forall x \in \mathbb{R}\) // Para provar que são L.I. na reta inteira R, impomos que a combinação linear seja zero para TODO x real.
02 \(\text{Testando em } x = 1: \;\; c_1(1)^2 + c_2(1)|1| = 0 \implies c_1 + c_2 = 0\) // Como a equação deve valer para todo x, escolhemos x = 1 e obtemos a 1ª equação do sistema.
03 \(\text{Testando em } x = -1: \;\; c_1(-1)^2 + c_2(-1)|-1| = 0 \implies c_1 - c_2 = 0\) // Escolhemos agora x = -1 (note que (-1)|-1| = -1· 1 = -1) e obtemos a 2ª equação.
04 \((c_1 + c_2) + (c_1 - c_2) = 0 \implies 2c_1 = 0 \implies c_1 = 0 \implies c_2 = 0\) // Somando as duas equações (Linhas 02 e 03), descobrimos que c1 = 0 e c2 = 0! Logo, f1 e f2 são L.I. em R!
Moral da História (Observação da Professora):
• Se duas funções são L.D., o Wronskiano é sempre zero.
• Se o Wronskiano é diferente de zero em algum ponto, as funções são com certeza L.I.
• Porém, \(W \equiv 0\) sozinho não garante que duas funções soltas sejam L.D. (como visto acima, pois \(f_1\) é uma parábola sempre \(\ge 0\) e \(f_2\) fica negativa para \(x < 0\)).

01 \(W(x) = \begin{vmatrix} e^{k_1 x} & e^{k_2 x} \\ k_1 e^{k_1 x} & k_2 e^{k_2 x} \end{vmatrix}\) // Montamos a matriz com as funções na 1ª linha e suas derivadas na 2ª linha.

03 \(k_1 \neq k_2 \implies k_2 - k_1 \neq 0 \implies W(x) \neq 0, \quad \forall x \in \mathbb{R}\) // Como a exponencial nunca zera e k2 ≠ k1, o Wronskiano nunca é nulo. Logo, são L.I.!
7. (b) Mostrar que \(e^{kx}\) e \(x e^{kx}\) são L.I. via Wronskiano.
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \((x e^{kx})' = (x)' e^{kx} + x(e^{kx})' = e^{kx} + k x e^{kx} = (1 + kx)e^{kx}\) // Calculamos antes a derivada da 2ª função usando a Regra do Produto.
02 \(W(x) = \begin{vmatrix} e^{kx} & x e^{kx} \\ k e^{kx} & (1 + kx)e^{kx} \end{vmatrix}\) // Substituímos as funções e suas derivadas no determinante Wronskiano.
03 \(W(x) = e^{kx}(1 + kx)e^{kx} - x e^{kx}(k e^{kx}) = e^{2kx}(1 + kx - kx) = e^{2kx} \neq 0\) // Os termos +kx e -kx se cancelam! Sobra apenas e2kx, que é sempre positivo (> 0). Logo, são L.I.!

Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(y_1' = \alpha e^{\alpha x}\cos(\beta x) - \beta e^{\alpha x}\sin(\beta x)\) // Derivamos y1 = eα xcos(β x) usando a Regra do Produto e Regra da Cadeia.

05 \(W(x) = \beta e^{2\alpha x} \underbrace{\left[\cos^2(\beta x) + \sin^2(\beta x)\right]}_{= 1} = \beta e^{2\alpha x} \neq 0\) // Usamos a relação fundamental cos2 + sen2 = 1. Como β ≠ 0 e e2α x > 0, temos W(x) ≠ 0. São L.I.!

⭐ Exercício 9 — Parâmetros de Soluções Fundamentais e Superposição

9. Considere a equação diferencial \((x + 3)y'' + (x + 2)y' - y = 0\). A função \(y_3(x) = 5e^{-x} + x + 2\) é solução da EDO? Responda sem substituir na equação.

03 \(e^{rx} \left[ (r^2 + r)x + (3r^2 + 2r - 1) \right] = 0\) // Dividimos por erx ≠ 0 e agrupamos os termos que multiplicam x e os termos constantes.
04 \(r^2 + r = 0 \implies r(r + 1) = 0 \implies r = 0 \;\;\text{ou}\;\; r = -1\) // Para zerar para todo x, o coeficiente de x deve ser zero (r2 + r = 0) E o termo constante também.

Tópico 3: EDOs Homogêneas com Coeficientes Constantes

Exercícios 10 e 11

🧠 O que você precisa lembrar de Álgebra e Números Complexos (Pré-Requisitos)

  • 1. Fórmula de Bhaskara (Equação de 2º Grau \(ar^2 + br + c = 0\)): \[\Delta = b^2 - 4ac \quad \implies \quad r = \frac{-b \pm \sqrt{\Delta}}{2a}\] Atenção: Se um termo não aparece na EDO, o coeficiente dele é zero! Por exemplo:
    • Em \(y'' - 4y = 0\), não tem \(y'\), logo \(a=1, b=0, c=-4 \implies r^2 - 4 = 0\).
    • Em \(y'' + y' = 0\), não tem \(y\) sem derivada, logo \(a=1, b=1, c=0 \implies r^2 + r = 0\). (Cuidado: \(y\) vira \(1 = r^0\), e \(y'\) vira \(r\)!).
  • 2. Raiz Quadrada de Número Negativo (Números Complexos): Quando \(\Delta < 0\), usamos a unidade imaginária \(i = \sqrt{-1}\) (\(i^2 = -1\)). Assim, para extrair a raiz de um número negativo, tiramos a raiz do valor positivo e multiplicamos por \(i\): \[\sqrt{-16} = \sqrt{16} \cdot \sqrt{-1} = 4i, \qquad \sqrt{-15} = \sqrt{15}\,i\] As raízes ficam na forma \(r = \alpha \pm i\beta\), onde \(\alpha\) é a parte real (o que não tem \(i\)) e \(\beta\) é a parte imaginária positiva (o número que multiplica o \(i\), sem o sinal \(\pm\) e sem a letra \(i\)!).

📘 Introdução ao Tema: A Equação Característica

Para resolver \(a y'' + b y' + c y = 0\) (onde \(a, b, c\) são números constantes), propomos a função exponencial \(y(x) = e^{rx}\). Como \(y' = r e^{rx}\) e \(y'' = r^2 e^{rx}\), ao substituir na EDO e dividir por \(e^{rx} \neq 0\), obtemos um polinômio de 2º grau chamado Equação Característica:

\[a r^2 + b r + c = 0\]

Basta substituir a ordem da derivada pela potência de \(r\): \(y'' \to r^2\), \(y' \to r\) e \(y \to 1\) (nunca troque \(y\) por \(r\)!).

Discriminante \(\Delta = b^2 - 4ac\) Tipo de Raízes Soluções Fundamentais \(\{y_1, y_2\}\) Solução Geral \(y(x)\)
Caso 1: \(\Delta > 0\) Reais e Distintas:
\(r_1 \neq r_2\)		 \(y_1 = e^{r_1 x}\)
\(y_2 = e^{r_2 x}\)		 \(y(x) = c_1 e^{r_1 x} + c_2 e^{r_2 x}\)
Caso 2: \(\Delta = 0\) Reais e Iguais (Dupla):
\(r_1 = r_2 = r\)		 \(y_1 = e^{rx}\)
\(y_2 = x e^{rx}\) (multiplica por \(x\))		 \(y(x) = c_1 e^{rx} + c_2 x e^{rx}\)
Caso 3: \(\Delta < 0\) Complexas Conjugadas:
\(r = \alpha \pm i\beta\)		 \(y_1 = e^{\alpha x}\cos(\beta x)\)
\(y_2 = e^{\alpha x}\sin(\beta x)\)		 \(y(x) = e^{\alpha x}[c_1 \cos(\beta x) + c_2 \sin(\beta x)]\)

  • 1. Derivada Primeira e Segunda de um Produto \(y_2(x) = u(x) \cdot y_1(x)\) (Cálculo 1):
    • 1ª Derivada: \(y_2' = u' y_1 + u y_1'\)
    • 2ª Derivada (derivando cada parcela pela Regra do Produto): \[y_2'' = (u'' y_1 + u' y_1') + (u' y_1' + u y_1'') = u'' y_1 + 2u' y_1' + u y_1''\]
  • 2. EDO de 1ª Ordem de Variáveis Separáveis (Conteúdo da P1): Quando chegamos em \(\frac{dw}{dx} = g(x) \cdot w\), passamos tudo que tem \(w\) para a esquerda e tudo que tem \(x\) para a direita e integramos: \[\int \frac{1}{w}\,dw = \int g(x)\,dx \implies \ln|w| = G(x) \implies w(x) = e^{G(x)}\] Lembrando também da propriedade mágica de logaritmo e exponencial: \(e^{\ln(A)} = A\) e \(k\ln(A) = \ln(A^k) \implies e^{k\ln(x)} = e^{\ln(x^k)} = x^k\).
  • 3. Integração por Frações Parciais (Cálculo 2): Usada no Exercício 12 para integrar \(\frac{1}{x^2(1-x^2)}\). Como \(x^2 + (1 - x^2) = 1\), podemos quebrar a fração diretamente em: \[\frac{1}{x^2(1-x^2)} = \frac{(1 - x^2) + x^2}{x^2(1-x^2)} = \frac{1 - x^2}{x^2(1-x^2)} + \frac{x^2}{x^2(1-x^2)} = \frac{1}{x^2} + \frac{1}{1 - x^2}\] E para \(\frac{1}{1 - x^2} = -\frac{1}{x^2 - 1} = -\frac{1}{(x-1)(x+1)}\), usamos \(\frac{1}{(x-1)(x+1)} = \frac{1/2}{x-1} - \frac{1/2}{x+1}\), cuja integral é \(\frac{1}{2}\ln\left|\frac{x-1}{x+1}\right|\).

📘 Introdução ao Tema: Como Achar \(y_2(x)\) Conhecendo \(y_1(x)\)

Quando os coeficientes da EDO \(y'' + p(x)y' + q(x)y = 0\) dependem de \(x\) (não são constantes!), não podemos usar Bhaskara. Porém, se o enunciado fornecer uma solução \(y_1(x)\), encontramos a segunda solução \(y_2(x)\) propondo:

\[y_2(x) = u(x) \cdot y_1(x)\]

Ao substituir \(y_2, y_2', y_2''\) na EDO, todos os termos com \(u(x)\) sem derivada se cancelam automaticamente (porque \(y_1\) já é solução!). Sobra apenas uma equação com \(u''\) e \(u'\). Fazendo a troca \(w(x) = u'(x)\) (logo \(u'' = w'\)), reduzimos para uma EDO de 1ª ordem separável!

🧠 O que você precisa lembrar de Polinômios e Limites (Pré-Requisitos de Cálculo 1)

  • 1. Forma Fatorada de uma Equação de 2º Grau: Se você já conhece as duas raízes \(r_1\) e \(r_2\) de uma equação de 2º grau, o polinômio que tem essas raízes é dado pelo produto: \[(r - r_1)(r - r_2) = 0 \quad \implies \quad r^2 - (r_1 + r_2)r + (r_1 \cdot r_2) = 0\]
  • 2. Limite de Exponencial Negativa no Infinito (\(\lim_{x\to\infty} e^{-kx}\) com \(k > 0\)): Quando o expoente vai para \(-\infty\), a exponencial encolhe rapidamente para zero: \[\lim_{x \to \infty} e^{-x} = \lim_{x \to \infty} \frac{1}{e^x} = \frac{1}{\infty} = 0\]
  • 3. Regra de L'Hôpital para Indeterminação \(\frac{\infty}{\infty}\) (Cálculo 1): No Exercício 15 aparece \(\lim_{x\to\infty} x e^{-x} = \lim_{x\to\infty} \frac{x}{e^x}\), que é do tipo \(\frac{\infty}{\infty}\). Pela Regra de L'Hôpital, derivamos o numerador e o denominador separadamente: \[\lim_{x \to \infty} \frac{x}{e^x} \;\; \overset{\text{L'H}}{=} \;\; \lim_{x \to \infty} \frac{(x)'}{(e^x)'} = \lim_{x \to \infty} \frac{1}{e^x} = \frac{1}{\infty} = 0\] Intuição: A função exponencial \(e^x\) cresce infinitamente mais rápido do que qualquer polinômio \(x\)!

📘 Introdução ao Tema: Engenharia Reversa e Análise Qualitativa de 2ª Ordem

  • Engenharia Reversa (Ex. 14): Olhando para a solução geral \(y(x)\), identificamos quais foram as raízes \(r_1\) e \(r_2\), montamos \((r - r_1)(r - r_2) = 0\), expandimos o polinômio e destrocamos \(r^2 \to y''\), \(r \to y'\) e \(1 \to y\).
  • Estabilidade / Limite quando \(x \to \infty\) (Ex. 15 e 16): Toda solução \(e^{rx}\) ou \(x e^{rx}\) vai para zero quando \(x \to \infty\) se e somente se a raiz for estritamente negativa (\(r < 0\)) (ou parte real \(\alpha < 0\) no caso complexo).

07 \(r = \frac{-2 \pm 0}{2} = -1 \implies y(x) = c_1 e^{-x} + c_2 x e^{-x} \quad (\text{para } \alpha = 1)\) // Com raiz dupla r = -1, a segunda solução recebe o fator multiplicativo x.
08 \(\text{CASO 3 } (\alpha > 1): \;\; 1 - \alpha < 0 \implies \Delta = -4(\alpha - 1) < 0 \quad (\text{Raízes Complexas})\) // Se α > 1, invertemos (1 - α) para -(α - 1) para deixar o número dentro da raiz positivo (α - 1 > 0).
09 \(r = \frac{-2 \pm \sqrt{-4(\alpha - 1)}}{2} = \frac{-2 \pm 2i\sqrt{\alpha - 1}}{2} = -1 \pm i\sqrt{\alpha - 1}\) // Temos parte real = -1 e parte imaginária β = √(α − 1).
10 \(\implies y(x) = e^{-x}\left[c_1 \cos\left(\sqrt{\alpha - 1}\,x\right) + c_2 \sin\left(\sqrt{\alpha - 1}\,x\right)\right] \quad (\text{para } \alpha > 1)\) // Solução geral oscilatória amortecida para α > 1.
✓ Resposta 18:
• Para \(\alpha < 1\): \(y(x) = c_1 e^{(-1 + \sqrt{1-\alpha})x} + c_2 e^{(-1 - \sqrt{1-\alpha})x}\)
• Para \(\alpha = 1\): \(y(x) = c_1 e^{-x} + c_2 x e^{-x}\)
• Para \(\alpha > 1\): \(y(x) = e^{-x}\left[c_1 \cos(\sqrt{\alpha - 1}\,x) + c_2 \text{sen}(\sqrt{\alpha - 1}\,x)\right]\)

💡 Resuminho & Recapitulação — Tópico 5

1. Truque da Raiz Negativa no Exercício 18 Quando \(\alpha > 1\), temos \(1 - \alpha < 0\). Para tirar a raiz quadrada sem se confundir com sinais, escreva \(1 - \alpha = -(\alpha - 1)\). Assim: \(\sqrt{1 - \alpha} = \sqrt{-1}\cdot\sqrt{\alpha - 1} = i\sqrt{\alpha - 1}\)!
2. Quando a Solução Vai para Zero no Infinito? \(\lim_{x\to\infty} y(x) = 0\) sempre que as raízes (ou a parte real \(\alpha\)) forem negativas, mesmo que haja um \(x\) multiplicando (\(x e^{-x} \to 0\) por L'Hôpital).

Tópico 6: EDOs Não Homogêneas — Método dos Coeficientes a Determinar

Exercícios 19, 20 e 21

🧠 O que você precisa lembrar de Polinômios e Identidade de Funções (Pré-Requisitos)

  • 1. Igualdade de Polinômios e Funções L.I. (Álgebra): Se uma igualdade como \((A)x^2 + (B)x + (C) = 1x^2 + 0x + 2\) vale para todo \(x\), então os coeficientes de mesma potência de \(x\) dos dois lados têm que ser iguais: \[A = 1, \qquad B = 0, \qquad C = 2\] O mesmo vale para seno e cosseno: se \((M)\cos(x) + (N)\sin(x) = 1\cos(x) + 0\sin(x)\), então \(M = 1\) e \(N = 0\).
  • 2. Um Polinômio de Grau \(n\) Precisa estar Completo no Palpite! Mesmo que no lado direito da EDO apareça apenas \(x^2\) (sem \(x\) e sem número constante), a derivada de \(x^2\) gera \(2x\) e \(2\). Por isso, o palpite para um termo de grau 2 deve ser o polinômio completo \(Ax^2 + Bx + C\)!

📘 Introdução ao Tema: Estrutura da Solução Geral Não Homogênea

Para resolver uma EDO Não Homogênea \(a y'' + b y' + c y = g(x)\), a solução geral \(y_{GNH}(x)\) é sempre a soma de duas partes:

\[y_{GNH}(x) = y_h(x) + y_p(x)\]
  1. \(y_h(x)\) (Solução da Homogênea associada): Resolve-se \(a y'' + b y' + c y = 0\) pela equação característica (como no Tópico 3). Carrega as constantes \(c_1\) e \(c_2\).
  2. \(y_p(x)\) (Solução Particular): É uma função específica (sem constantes arbitrárias \(c_1, c_2\)) que, substituída na EDO, produz exatamente o lado direito \(g(x)\).

⚠️ A Regra de Ouro da Ressonância: Sempre ache \(y_h(x)\) PRIMEIRO! Se o palpite que você ia usar para \(y_p(x)\) já aparecer dentro de \(y_h(x)\), ele vai zerar ao ser substituído na EDO! Para corrigir isso, multiplique o palpite por \(x\) (ou por \(x^2\) se for raiz dupla da homogênea).

  • 2. Integral por Substituição Simples \(\int \frac{u'}{u}\,dx = \ln|u|\) (Cálculo 1): Quando o numerador é a derivada do denominador, a integral é o logaritmo natural do denominador!
    • \(\int \text{tg}(u)\,du = \int \frac{\sin(u)}{\cos(u)}\,du = -\ln|\cos(u)|\) (pois a derivada de \(\cos u\) é \(-\sin u\)).
    • \(\int \text{cotg}(u)\,du = \int \frac{\cos(u)}{\sin(u)}\,du = \ln|\sin(u)|\) (pois a derivada de \(\sin u\) é \(\cos u\)).
  • 3. Integral da Cossecante \(\int \frac{1}{\sin x}\,dx\) (Tabela de Cálculo 1): \[\int \frac{1}{\sin(x)}\,dx = \int \text{cossec}(x)\,dx = \ln\left|\text{tg}\left(\frac{x}{2}\right)\right| = \ln|\text{cossec}(x) - \text{cotg}(x)|\]

📘 Introdução ao Tema: Quando e Como Usar Variação dos Parâmetros

O Método dos Coeficientes a Determinar (Tópico 6) NÃO funciona quando o lado direito \(g(x)\) tem divisões por \(x\) (como \(\frac{e^{3x}}{x^2}\)), logaritmos (\(\ln x\)) ou funções trigonométricas com denominador (\(\text{tg}\,x, \text{cotg}\,x, \sec x, \text{cossec}\,x\)), porque as derivadas dessas funções geram infinitos termos novos.

O Método da Variação dos Parâmetros resolve qualquer \(g(x)\)! A ideia é pegar a solução homogênea \(y_h(x) = c_1 y_1(x) + c_2 y_2(x)\) e trocar as constantes \(c_1, c_2\) por funções desconhecidas \(u_1(x)\) e \(u_2(x)\):

\[y_p(x) = u_1(x) y_1(x) + u_2(x) y_2(x)\]
📐 Formulário Oficial — Método da Variação dos Parâmetros
Passo do Algoritmo Fórmula Matemática Dica de Ouro para a Prova
1. Forma Padrão e \(y_h\) \(y'' + p(x)y' + q(x)y = g(x)\)
\(y_h(x) = c_1 y_1(x) + c_2 y_2(x)\)		 Verifique se o coeficiente de \(y''\) é \(1\)! Identifique quem é \(y_1(x)\), \(y_2(x)\) e \(g(x)\).
2. Wronskiano \(W\) \(W = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_2 y_1'\) Calcule e simplifique o Wronskiano antes de montar as integrais.
3. Cálculo de \(u_1(x)\) e \(u_2(x)\) \(u_1(x) = -\int \frac{y_2(x)\cdot g(x)}{W(x)}\,dx\)
\(u_2(x) = +\int \frac{y_1(x)\cdot g(x)}{W(x)}\,dx\)		 Cuidado com o sinal: \(u_1\) tem sinal de MENOS (\(-\)) e leva \(y_2\) no numerador; \(u_2\) tem sinal de MAIS (\(+\)) e leva \(y_1\)!
4. Montagem de \(y_p(x)\) \(y_p(x) = u_1(x) y_1(x) + u_2(x) y_2(x)\) Multiplique \(u_1\) por \(y_1\) e \(u_2\) por \(y_2\) e simplifique!

🧠 O que você precisa lembrar de Potências, Logaritmos e Fórmula de Euler (Pré-Requisitos)

  • 1. Multiplicação de Potências de Mesma Base (Álgebra Básica): Conserva-se a base e somam-se os expoentes: \[x^2 \cdot x^{r-2} = x^{2 + r - 2} = x^r \qquad \text{e} \qquad x^1 \cdot x^{r-1} = x^{1 + r - 1} = x^r\]
  • 2. Como Reescrever \(x^{i\beta}\) usando Exponencial e Logaritmo (Cálculo / Complexos): Como exponencial e logaritmo natural são funções inversas, todo número positivo \(x > 0\) pode ser escrito como \(x = e^{\ln x}\). Elevando a \(i\beta\): \[x^{i\beta} = \left(e^{\ln x}\right)^{i\beta} = e^{i(\beta \ln x)} = \cos(\beta \ln x) + i\sin(\beta \ln x)\] É por isso que, nas equações de Cauchy-Euler, dentro do seno e do cosseno aparece \(\beta \ln(x)\) em vez de \(\beta x\)!

📘 Introdução ao Tema: Como Reconhecer e Resolver uma Equação de Cauchy-Euler

Uma equação de Cauchy-Euler tem coeficientes variáveis muito especiais: a potência de \(x\) empata com a ordem da derivada em cada termo (\(x^2\) multiplica \(y''\), \(x^1\) multiplica \(y'\), e \(x^0=1\) multiplica \(y\)):

\[a x^2 y'' + b x y' + c y = 0 \quad (\text{para } x > 0)\]

Em vez de chutar \(e^{rx}\), chutamos a potência \(y(x) = x^r\)! Substituindo \(y' = r x^{r-1}\) e \(y'' = r(r-1)x^{r-2}\), caímos na Equação Indicial:

\[a r(r - 1) + b r + c = 0 \quad \iff \quad a r^2 + (b - a)r + c = 0\]

Atenção máxima: O coeficiente de \(r\) na equação indicial é \((b - a)\) (ou \(b - 1\) quando \(a = 1\)), e não \(b\)! Isso acontece porque a segunda derivada \(y''\) traz o fator \(r(r - 1) = r^2 - r\).

\(r^2 + (b-1)r + c = 0\)		 Tipo de Raízes Soluções Fundamentais \(\{y_1, y_2\}\) Solução Geral \(y(x)\) (\(x > 0\))
Caso 1: \(\Delta > 0\) Reais e Distintas:
\(r_1 \neq r_2\)		 \(y_1 = x^{r_1}\)

\(r_1 = r_2 = r\)		 \(y_1 = x^r\)
\(y_2 = x^r \ln(x)\) (multiplica por \(\ln x\))		 \(y(x) = c_1 x^r + c_2 x^r \ln(x)\)
Caso 3: \(\Delta < 0\) Complexas Conjugadas:
\(r = \alpha \pm i\beta\)		 \(y_1 = x^\alpha \cos(\beta \ln x)\)

02 \(y'' + \frac{b}{x}y' + \frac{c}{x^2}y = 0 \implies p(x) = \frac{b}{x}\) // Colocamos a EDO na forma padrão dividindo por x2 para usar a Redução de Ordem (Fórmula de Abel).
03 \(u'(x) = \frac{e^{-\int \frac{b}{x}dx}}{[y_1(x)]^2} = \frac{e^{-b\ln x}}{\left(x^{\frac{1-b}{2}}\right)^2} = \frac{x^{-b}}{x^{1 - b}} = x^{-b - (1 - b)} = x^{-1} = \frac{1}{x}\) // Pela Fórmula de Abel, os termos com b se cancelam no expoente e sobra u'(x) = 1/x!
04 \(u(x) = \int \frac{1}{x}\,dx = \ln(x) \implies y_2(x) = y_1(x)\cdot u(x) = x^{\frac{1-b}{2}}\ln(x)\) // Integrando u'(x) = 1/x obtemos u(x) = ln(x), provando que a 2ª solução ganha o fator ln(x)!

25. (a) \(x^2 y'' - 3xy' + 4y = 0\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(a = 1, \;\; b = -3, \;\; c = 4 \implies r^2 + (b - 1)r + c = 0\) // Identificamos que é uma equação de Cauchy-Euler com b = -3 e c = 4.
02 \(r^2 + (-3 - 1)r + 4 = 0 \implies r^2 - 4r + 4 = 0\) // Montamos a equação indicial. CUIDADO: o coeficiente de r fica -3 - 1 = -4!
03 \((r - 2)^2 = 0 \implies r_1 = r_2 = 2 \quad (\text{Raiz real dupla!})\) // Fatoramos o quadrado perfeito (ou usamos Bhaskara: Δ = 16 - 16 = 0). Raiz repetida r = 2.
04 \(y_1(x) = x^2 \;\;\text{e}\;\; y_2(x) = x^2 \ln(x)\) // Pelo Caso 2 de Cauchy-Euler, a segunda solução recebe o multiplicador ln(x) (e não x!).
05 \(y(x) = c_1 x^2 + c_2 x^2 \ln(x), \quad x > 0\) // Escrevemos a solução geral combinando y1 e y2.
✓ Resposta 25(a): \(y(x) = c_1 x^2 + c_2 x^2 \ln(x)\) para \(x > 0\).
25. (b) \(x^2 y'' + 3xy' + 5y = 0\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(a = 1, \;\; b = 3, \;\; c = 5 \implies r^2 + (3 - 1)r + 5 = 0 \implies r^2 + 2r + 5 = 0\) // Montamos a equação indicial fazendo b - 1 = 3 - 1 = 2.
02 \(\Delta = 2^2 - 4(1)(5) = 4 - 20 = -16 < 0\) // Calculamos o discriminante: Δ = -16 < 0 (Caso 3: raízes complexas conjugadas).
03 \(r = \frac{-2 \pm \sqrt{-16}}{2} = \frac{-2 \pm 4i}{2} = -1 \pm 2i \implies \alpha = -1, \;\; \beta = 2\) // Extraímos as raízes: parte real α = -1 e parte imaginária β = 2.
04 \(y_1(x) = x^{-1}\cos(2\ln x) \;\;\text{e}\;\; y_2(x) = x^{-1}\sin(2\ln x)\) // Montamos o par fundamental de Cauchy-Euler com x^α = x-1 = 1/x e argumento 2ln(x).
05 \(y(x) = c_1 \frac{1}{x}\cos(2\ln x) + c_2 \frac{1}{x}\sin(2\ln x), \quad x > 0\) // Escrevemos a solução geral.
✓ Resposta 25(b): \(y(x) = \frac{1}{x}\left[c_1 \cos(2\ln x) + c_2 \text{sen}(2\ln x)\right]\) para \(x > 0\).
25. (c) \(x^2 y'' + 4xy' + 2y = 0\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(a = 1, \;\; b = 4, \;\; c = 2 \implies r^2 + (4 - 1)r + 2 = 0 \implies r^2 + 3r + 2 = 0\) // Montamos a equação indicial fazendo b - 1 = 4 - 1 = 3.
02 \((r + 1)(r + 2) = 0 \implies r_1 = -1 \;\;\text{e}\;\; r_2 = -2\) // Resolvemos por soma e produto (ou Bhaskara: Δ = 9 - 8 = 1). Duas raízes reais distintas!
03 \(y_1(x) = x^{-1} = \frac{1}{x} \;\;\text{e}\;\; y_2(x) = x^{-2} = \frac{1}{x^2}\) // Pelo Caso 1 de Cauchy-Euler, as soluções fundamentais são as potências x-1 e x-2.
04 \(y(x) = c_1 \frac{1}{x} + c_2 \frac{1}{x^2}, \quad x > 0\) // Escrevemos a solução geral.
✓ Resposta 25(c): \(y(x) = c_1 x^{-1} + c_2 x^{-2} = \frac{c_1}{x} + \frac{c_2}{x^2}\) para \(x > 0\).

💡 Resuminho & Recapitulação — Tópico 8 (Cauchy-Euler vs. Coeficientes Constantes)

1. Comparação Direta (Não Confunda!) • Coef. Constantes (\(ay'' + by' + cy = 0\)): Equação \(ar^2 + br + c = 0\); usa \(e^{rx}\); raiz dupla multiplica por \(x\); complexa usa \(\cos(\beta x)\).
• Cauchy-Euler (\(ax^2y'' + bxy' + cy = 0\)): Equação \(ar(r-1) + br + c = 0\); usa \(x^r\); raiz dupla multiplica por \(\ln(x)\); complexa usa \(\cos(\beta\ln x)\).
2. Como Nunca Esquecer o \((b - 1)\) da Indicial Em vez de decorar \(r^2 + (b-1)r + c = 0\), basta lembrar que \(x^2 y''\) vira SEMPRE \(r(r - 1)\)! Assim, em \(x^2y'' - 3xy' + 4y = 0\), escreva direto: \(r(r-1) - 3r + 4 = 0 \implies r^2 - 4r + 4 = 0\). Zero chance de erro!
