Consulta Rápida Pré-Prova

1. EDOs Homogêneas (Coef. Constantes vs. Cauchy-Euler)

Caso \(ay'' + by' + cy = 0\)
(\(ar^2 + br + c = 0\))		 \(ax^2y'' + bxy' + cy = 0\)
(\(ar(r-1) + br + c = 0\))
\(\Delta > 0\)
\(r_1 \neq r_2\)		 \(c_1 e^{r_1 x} + c_2 e^{r_2 x}\) \(c_1 x^{r_1} + c_2 x^{r_2}\)
\(\Delta = 0\)
\(r_1 = r_2 = r\)		 \(c_1 e^{rx} + c_2 \mathbf{x} e^{rx}\) \(c_1 x^r + c_2 x^r \mathbf{\ln|x|}\)
\(\Delta < 0\)
\(\lambda \pm i\mu\)		 \(e^{\lambda x}(c_1\cos\mu x + c_2\sin\mu x)\) \(x^{\lambda}[c_1\cos(\mu\ln x) + c_2\sin(\mu\ln x)]\)
  • Wronskiano: \(W(y_1, y_2) = y_1 y_2' - y_1' y_2 \neq 0 \implies\) L.I.
  • Redução de Ordem: Se conhece \(y_1\), chute \(y_2(x) = v(x)y_1(x)\).

2. EDOs Não Homogêneas (\(y = y_h + y_p\))

  • Coeficientes a Determinar (MCD): Apenas para coef. constantes e \(g(x)\) = polinômio, \(e^{\alpha x}\), \(\sin(\beta x)\) ou \(\cos(\beta x)\).
    • Regra de Ouro da Ressonância: Se o chute inicial já aparece em \(y_h\), multiplique por \(x\) (ou \(x^2\) se for raiz dupla!).
  • Variação de Parâmetros (MVP): Funciona para qualquer \(g(x)\) (ex: \(\text{tg } x, \sec x, e^x/x\)).
    1. Cuidado 0: Divida por \(a(x)\) para deixar \(1\cdot y'' + P(x)y' + Q(x)y = g(x)\)!
    2. Solução: \(y_p = u_1(x)y_1(x) + u_2(x)y_2(x)\), onde:
\[u_1' = \frac{-y_2(x)g(x)}{W(y_1, y_2)} \quad \text{e} \quad u_2' = \frac{+y_1(x)g(x)}{W(y_1, y_2)}\]

3. Oscilações Mecânicas (\(mu'' + cu' + ku = F_0\cos\Omega t\))

  • MHS Livre (\(c=0\)): \(\omega_0 = \sqrt{k/m}\), Período \(T = \frac{2\pi}{\omega_0}\). Forma: \(u(t) = A\cos(\omega_0 t - \phi)\), com \(A = \sqrt{c_1^2 + c_2^2}\) e \(\tan\phi = c_2/c_1\).
  • Amortecimento Livre (\(c > 0\), \(\Delta = c^2 - 4mk\)):
    • \(c^2 > 4mk\) (Superamortecido): volta a zero sem oscilar.
    • \(c^2 = 4mk\) (Crítico, \(c_{\text{cr}} = 2\sqrt{mk}\)): limiar sem oscilação.
    • \(c^2 < 4mk\) (Subamortecido): oscila com amortecimento \(e^{-\frac{c}{2m}t}\) e quase-frequência \(\tilde{\omega} = \frac{\sqrt{4mk - c^2}}{2m}\).
  • Ressonância Pura (\(c=0, \Omega = \omega_0\)): Chute multiplicado por \(t\): \(u_p(t) = t(A\cos\omega_0 t + B\sin\omega_0 t) \implies\) amplitude explode!

4. Séries Numéricas, Potências e Maclaurin

  • Testes Rápidos: Termo Geral (\(\lim a_n \neq 0 \Rightarrow\) Div.); Geométrica \(\sum r^n = \frac{a_1}{1-r}\) (\(|r|<1\)); \(p\)-série \(\sum \frac{1}{n^p}\) (Conv. \(\iff p>1\)); Comparação de Polinômios (\(\text{grau}_{\text{den}} - \text{grau}_{\text{num}} > 1 \Rightarrow\) Conv.).
  • Alternadas \(\sum (-1)^n b_n\): 1) Se \(\sum b_n\) conv. \(\Rightarrow\) Absoluta; 2) Se \(\sum b_n\) div., mas \(b_n \downarrow 0\) (Leibniz) \(\Rightarrow\) Condicional.
  • Teste da Razão & Potências: \(L = \lim \left|\frac{u_{n+1}}{u_n}\right| < 1 \implies\) acha o intervalo aberto \((x_0-R, x_0+R)\). Sempre teste os 2 extremos!
  • Maclaurin (\(x_0=0\)): \(\frac{1}{1-x} = \sum x^n\) (\(R=1\)); \(e^x = \sum \frac{x^n}{n!}\) (\(R=\infty\)); \(\sin x = \sum \frac{(-1)^n x^{2n+1}}{(2n+1)!}\); \(\cos x = \sum \frac{(-1)^n x^{2n}}{(2n)!}\); \(\text{arctg } x = \sum \frac{(-1)^n x^{2n+1}}{2n+1}\). Coeficiente de Taylor: \(c_k = \frac{f^{(k)}(x_0)}{k!}\).

Gabarito — Questão 1 (EDOs Homogêneas & Cauchy-Euler) 20 Pontos
Item (a) — Parâmetro \(\alpha\) em \(y'' + 2\alpha y' + 9y = 0\) e P.V.I. para \(\alpha = 3\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(r^2 + 2\alpha r + 9 = 0 \implies r = \frac{-2\alpha \pm \sqrt{4\alpha^2 - 36}}{2} = -\alpha \pm \sqrt{\alpha^2 - 9}\) // Montamos a equação característica trocando y^(n) por r^n e aplicamos Bhaskara simplificado.
02 \(\text{(i) Sem oscilar: } \alpha^2 - 9 \ge 0 \iff \mathbf{\alpha \ge 3}\) // Para não oscilar, não pode haver seno/cosseno, logo o discriminante deve ser ≥ 0 (raízes reais negativas, pois -α ± √(α²-9) < 0 para α ≥ 3).
03 \(\text{(ii) Oscilando: } \alpha^2 - 9 < 0 \;\; (\text{com } \alpha > 0) \iff \mathbf{0 < \alpha < 3}\) // Para oscilar tendendo a zero, as raízes devem ser complexas conjugadas com parte real negativa (-α < 0), o que ocorre para 0 < α < 3.
04 \(\text{Para } \alpha = 3: \;\; r = -3 \text{ (raiz dupla)} \implies y(x) = c_1 e^{-3x} + c_2 x e^{-3x}\) // Quando α = 3, Δ = 0 e temos raiz dupla r = -3. Multiplicamos a segunda solução por x!
05 \(y(0) = 1 \implies c_1 = 1; \quad y'(x) = -3e^{-3x} + c_2(e^{-3x} - 3xe^{-3x})\) // Aplicamos y(0) = 1 achando c₁ = 1 e derivamos pela Regra do Produto para aplicar y'(0) = 0.
06 \(y'(0) = -3 + c_2 = 0 \implies c_2 = 3 \implies \mathbf{y(x) = e^{-3x} + 3xe^{-3x}}\) // Substituindo x = 0 em y'(x), obtemos c₂ = 3 e fechamos a solução do P.V.I.!
✅ Resposta Q1(a): (i) Sem oscilar: \(\alpha \ge 3\); (ii) Oscilando: \(0 < \alpha < 3\). P.V.I.: \(y(x) = e^{-3x} + 3xe^{-3x}\).
Item (b) — Cauchy-Euler: \(x^2 y'' - 3xy' + 4y = 0\) (\(x > 0\))
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(y = x^r \implies x^2 r(r - 1)x^{r-2} - 3x r x^{r-1} + 4x^r = 0\) // Equação de Cauchy-Euler: substituímos y = x^r, y' = r x^(r-1) e y'' = r(r-1)x^(r-2).
02 \(r(r - 1) - 3r + 4 = 0 \implies r^2 - 4r + 4 = 0 \implies (r - 2)^2 = 0\) // Lembrete: o coeficiente de r é (b - a) = -3 - 1 = -4. Fatorando o trinômio quadrado perfeito, achamos raiz dupla!
03 \(r_1 = r_2 = 2 \implies \mathbf{y(x) = c_1 x^2 + c_2 x^2 \ln(x)} \quad (x > 0)\) // Cuidado clássico de prova: em Cauchy-Euler, raiz dupla multiplica por ln(x) (e NÃO por x)!
✅ Resposta Q1(b): \(y(x) = c_1 x^2 + c_2 x^2 \ln(x)\).
Gabarito — Questão 2 (EDOs Não Homogêneas: MCD e MVP) 25 Pontos
Item (a) — Coeficientes a Determinar com Ressonância Dupla: \(y'' - 4y' + 4y = 6e^{2x}\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(y'' - 4y' + 4y = 0 \implies r^2 - 4r + 4 = (r - 2)^2 = 0 \implies y_h(x) = c_1 e^{2x} + c_2 x e^{2x}\) // Passo 1 (Solução Homogênea): r = 2 é raiz DUPLA da característica, logo yh já contém e^(2x) e x·e^(2x)!
02 \(g(x) = 6e^{2x} \implies \text{Chute inicial } A e^{2x} \text{ colide duas vezes!} \implies \mathbf{y_p(x) = A x^2 e^{2x}}\) // Passo 2 (Regra da Ressonância no MCD): Como e^(2x) e x·e^(2x) já estão em yh, multiplicamos por x²!
03 \(y_p' = A(2x + 2x^2)e^{2x}; \quad y_p'' = A(2 + 8x + 4x^2)e^{2x}\) // Derivamos yp duas vezes aplicando a Regra do Produto.
04 \(y_p'' - 4y_p' + 4y_p = A\left[(2 + 8x + 4x^2) - 4(2x + 2x^2) + 4x^2\right]e^{2x} = 2A e^{2x}\) // Substituindo na EDO, todos os termos com x e x² se cancelam (isso sempre ocorre na ressonância!), sobrando apenas 2A·e^(2x).
05 \(2A e^{2x} = 6e^{2x} \implies A = 3 \implies \mathbf{y(x) = c_1 e^{2x} + c_2 x e^{2x} + 3x^2 e^{2x}}\) // Igualando a 6e^(2x), achamos A = 3 e somamos yh + yp.
✅ Resposta Q2(a): \(y(x) = c_1 e^{2x} + c_2 x e^{2x} + 3x^2 e^{2x}\).
Item (b) — Variação de Parâmetros: \(y'' + y = \text{tg}(x)\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(y'' + y = 0 \implies r^2 + 1 = 0 \implies r = \pm i \implies y_1 = \cos(x), \;\; y_2 = \sin(x)\) // Passo 1: Resolvemos a homogênea e identificamos y₁ = cos(x) e y₂ = sen(x).
02 \(W(\cos x, \sin x) = \begin{vmatrix} \cos x & \sin x \\ -\sin x & \cos x \end{vmatrix} = \cos^2(x) + \sin^2(x) = 1\) // Passo 2: Calculamos o Wronskiano W = y₁y₂' - y₁'y₂ = 1.
03 \(u_1' = \frac{-y_2 g(x)}{W} = -\sin(x)\text{tg}(x) = -\frac{\sin^2(x)}{\cos(x)} = \frac{\cos^2(x) - 1}{\cos(x)} = \cos(x) - \sec(x)\) // Passo 3: Montamos u₁' usando tg(x) = sen(x)/cos(x) e a identidade sen²(x) = 1 - cos²(x).
04 \(u_1(x) = \int (\cos x - \sec x)\,dx = \sin(x) - \ln|\sec x + \text{tg } x|\) // Integramos u₁' (lembrando da integral tabelada de sec(x): ln|sec x + tg x|).
05 \(u_2' = \frac{y_1 g(x)}{W} = \cos(x)\frac{\sin(x)}{\cos(x)} = \sin(x) \implies u_2(x) = \int \sin(x)\,dx = -\cos(x)\) // Passo 4: Montamos u₂', que simplifica direto para sen(x), cuja integral é -cos(x).
06 \(y_p = u_1 \cos x + u_2 \sin x = \sin x\cos x - \cos x\ln|\sec x + \text{tg } x| - \cos x\sin x\) // Passo 5: Montamos yp = u₁y₁ + u₂y₂. Os termos sen(x)cos(x) se cancelam!
07 \(\mathbf{y(x) = c_1\cos(x) + c_2\sin(x) - \cos(x)\ln|\sec(x) + \text{tg}(x)|}\) // Escrevemos a solução geral y = yh + yp.
✅ Resposta Q2(b): \(y(x) = c_1\cos(x) + c_2\sin(x) - \cos(x)\ln|\sec(x) + \text{tg}(x)|\).
Gabarito — Questão 3 (Oscilações Mecânicas e Ressonância) 15 Pontos
Item (a) — Amortecimento Crítico e MHS na forma Amplitude-Fase
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(u'' + cu' + 16u = 0 \implies \Delta = c^2 - 4(1)(16) = c^2 - 64\) // Na equação mu'' + cu' + ku = 0 com m = 1 e k = 16, o discriminante da característica é Δ = c² - 64.
02 \(\text{Amortecimento Crítico: } \Delta = 0 \iff c^2 = 64 \implies \mathbf{c = 8\text{ N}\cdot\text{s/m}}\) // O amortecimento crítico ocorre exatamente na fronteira Δ = 0 (como c > 0, c = 8).
03 \(\text{Para } c = 0: \;\; u'' + 16u = 0 \implies \mathbf{\omega_0 = \sqrt{16} = 4\text{ rad/s}} \quad \text{e} \quad \mathbf{T = \frac{2\pi}{4} = \frac{\pi}{2}\text{ s}}\) // Sem amortecimento (MHS), a frequência natural é ω₀ = √(k/m) = 4 rad/s e o período é T = 2π/ω₀ = π/2 s.
04 \(u(t) = c_1\cos(4t) + c_2\sin(4t); \quad u(0)=1 \Rightarrow c_1 = 1; \quad u'(0)=4c_2=4 \Rightarrow c_2 = 1\) // Aplicando u(0) = 1 e u'(0) = 4 na solução geral livre, obtemos c₁ = 1 e c₂ = 1.
05 \(A = \sqrt{c_1^2 + c_2^2} = \sqrt{1^2 + 1^2} = \mathbf{\sqrt{2}\text{ m}}; \quad \tan\phi = \frac{1}{1} = 1 \Rightarrow \phi = \frac{\pi}{4}\) // Calculamos a amplitude A = √2 m e o ângulo de fase φ = π/4 rad (45°).
06 \(\mathbf{u(t) = \sqrt{2}\cos\left(4t - \frac{\pi}{4}\right)\text{ m}}\) // Escrevemos a equação do movimento na forma amplitude-fase pedida.
✅ Resposta Q3(a): \(c_{\text{cr}} = 8\text{ N}\cdot\text{s/m}\); \(\omega_0 = 4\text{ rad/s}\), \(A = \sqrt{2}\text{ m}\), \(T = \frac{\pi}{2}\text{ s}\) e \(u(t) = \sqrt{2}\cos\left(4t - \frac{\pi}{4}\right)\).
Item (b) — Frequência de Ressonância Pura e Forma de \(u_p(t)\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(u'' + 16u = 8\cos(\Omega t) \implies \text{Ressonância Pura ocorre quando } \mathbf{\Omega = \omega_0 = 4\text{ rad/s}}\) // A ressonância pura em um sistema não amortecido ocorre quando a frequência externa Ω iguala a frequência natural ω₀ = 4 rad/s.
02 \(\text{Para } \Omega = 4: \;\; \mathbf{u_p(t) = t\left(A\cos(4t) + B\sin(4t)\right)} \quad (\text{ou } B\,t\sin(4t))\) // Como cos(4t) e sen(4t) já resolvem a equação homogênea, multiplicamos o chute padrão por t!
03 \(\text{Quando } t \to +\infty, \text{ o fator } t \text{ faz a amplitude crescer ilimitadamente } (\to +\infty)!\) // Explicação física: as oscilações crescem linearmente dentro do envelope ±B·t, levando ao colapso/ruptura da mola.
✅ Resposta Q3(b): Ressonância em \(\Omega = 4\text{ rad/s}\); \(u_p(t) = t(A\cos 4t + B\sin 4t)\) com amplitude tendendo a \(+\infty\).
Gabarito — Questão 4 (Séries Numéricas e Alternadas) 20 Pontos
Item (a) — Testes de Convergência para (i) e (ii)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(\text{(i) } a_n = \frac{n + 3}{n^3 + 2n + 1} \sim \frac{n}{n^3} = \frac{1}{n^2} \quad (\text{escolhemos } b_n = \frac{1}{n^2})\) // Item (i): Olhando apenas os maiores graus (grau 1 em cima, grau 3 embaixo), comparamos com a p-série ∑(1/n²).
02 \(L = \lim_{n \to \infty} \frac{a_n}{1/n^2} = \lim_{n \to \infty} \frac{n^3 + 3n^2}{n^3 + 2n + 1} = 1 \quad (0 < L < \infty) \implies \mathbf{\text{(i) CONVERGE!}}\) // Pelo Critério da Comparação no Limite, como L = 1 > 0 e ∑(1/n²) converge (p = 2 > 1), a série (i) CONVERGE!
03 \(\text{(ii) } a_n = \frac{3^n n!}{n^n} \implies L = \lim_{n \to \infty} \frac{a_{n+1}}{a_n} = \lim_{n \to \infty} \frac{3^{n+1}(n+1)!}{(n+1)^{n+1}} \cdot \frac{n^n}{3^n n!}\) // Item (ii): Como há fatorial n! e potência n^n, aplicamos o Teste da Razão!
04 \(L = \lim_{n \to \infty} \frac{3 \cdot (n+1)n!}{(n+1)(n+1)^n} \cdot \frac{n^n}{n!} = 3 \cdot \lim_{n \to \infty} \frac{1}{(1 + 1/n)^n} = \frac{3}{e}\) // Simplificamos (n+1)! = (n+1)n! e (n+1)^(n+1) = (n+1)(n+1)^n. Como (1 + 1/n)^n → e ≈ 2,718, o limite vale L = 3/e.
05 \(e \approx 2,718 < 3 \implies L = \frac{3}{e} > 1 \implies \mathbf{\text{(ii) DIVERGE (pelo Teste da Razão)!}}\) // Como 3 > e, a razão L = 3/e ≈ 1,103 é MAIOR que 1! Logo, pelo Teste da Razão, a série (ii) DIVERGE!

Item (b) — Classificação da Série Alternada \(\sum (-1)^{n+1} \frac{1}{\sqrt{n+3}}\)

Item (a) — Raio e Intervalo de Convergência de \(\sum \frac{(x-2)^n}{n \cdot 3^n}\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(u_n(x) = \frac{(x - 2)^n}{n \cdot 3^n} \implies L = \lim_{n \to \infty} \left|\frac{(x - 2)^{n+1}}{(n+1)3^{n+1}} \cdot \frac{n \cdot 3^n}{(x - 2)^n}\right| = \frac{|x - 2|}{3} \lim_{n \to \infty} \frac{n}{n+1} = \frac{|x - 2|}{3}\) // Passo 1 (Raio de Convergência): Aplicamos o Teste da Razão.
02 \(L < 1 \iff \frac{|x - 2|}{3} < 1 \iff |x - 2| < 3 \iff -3 < x - 2 < 3 \iff -1 < x < 5 \quad (\mathbf{R = 3})\) // O raio de convergência é R = 3 (centrado em x₀ = 2), gerando o intervalo aberto (-1, 5). Testemos os extremos x = -1 e x = 5:
03 \(\text{Em } x = -1: \;\; \sum_{n=1}^{\infty} \frac{(-1 - 2)^n}{n \cdot 3^n} = \sum_{n=1}^{\infty} \frac{(-3)^n}{n \cdot 3^n} = \sum_{n=1}^{\infty} \frac{(-1)^n}{n} \implies \text{CONVERGE (Leibniz!)}\) // Passo 2 (Extremo x = -1): Cortando 3^n, obtemos a Série Harmônica Alternada, que converge pelo Critério de Leibniz! Logo, x = -1 ENTRA.
04 \(\text{Em } x = 5: \;\; \sum_{n=1}^{\infty} \frac{(5 - 2)^n}{n \cdot 3^n} = \sum_{n=1}^{\infty} \frac{3^n}{n \cdot 3^n} = \sum_{n=1}^{\infty} \frac{1}{n} \implies \text{DIVERGE (Harmônica } p=1\text{)}\) // Passo 3 (Extremo x = 5): Cortando 3^n, caímos na Série Harmônica ∑(1/n), que diverge! Logo, x = 5 NÃO entra.
05 \(\mathbf{R = 3 \quad \text{e} \quad I = [-1, 5)}\) // Fechamos em -1 e deixamos aberto em 5: intervalo de convergência [-1, 5).
✅ Resposta Q5(a): Raio \(R = 3\) e Intervalo de Convergência \(I = [-1, 5)\).
Item (b) — Série de Maclaurin de \(f(x) = x^2 e^{-x^3}\) e cálculo de \(f^{(11)}(0)\)
Resolução Passo a Passo (Referencie pelo Nº da Linha)
01 \(e^u = \sum_{n=0}^{\infty} \frac{u^n}{n!} \quad (R = \infty) \implies e^{-x^3} = \sum_{n=0}^{\infty} \frac{(-x^3)^n}{n!} = \sum_{n=0}^{\infty} \frac{(-1)^n}{n!} x^{3n}\) // Passo 1: Substituímos u = -x³ na série de Maclaurin de e^u. Como (-x³)^n = (-1)^n · x^(3n), a série converge para todo x ∈ ℝ.
02 \(f(x) = x^2 e^{-x^3} = x^2 \sum_{n=0}^{\infty} \frac{(-1)^n}{n!} x^{3n} = \mathbf{\sum_{n=0}^{\infty} \frac{(-1)^n}{n!} x^{3n+2}} \quad (\mathbf{R = \infty})\) // Passo 2: Multiplicamos termo a termo por x², somando +2 no expoente de x: x^(3n+2). O raio continua R = ∞.
03 \(\text{Pela Fórmula de Taylor em } x_0 = 0: \;\; c_k = \frac{f^{(k)}(0)}{k!} \implies \text{Queremos o termo de grau } k = 11!\) // Passo 3 (Achar f^(11)(0) sem derivar!): Na série de Maclaurin, o coeficiente de x11 é sempre f^(11)(0) / 11!.
04 \(3n + 2 = 11 \implies 3n = 9 \implies n = 3 \implies \text{Coeficiente de } x^{11} \text{ é } c_{11} = \frac{(-1)^3}{3!} = -\frac{1}{6}\) // Igualamos o expoente geral 3n + 2 a 11, descobrindo que o termo x11 ocorre exatamente para n = 3!
05 \(\frac{f^{(11)}(0)}{11!} = -\frac{1}{3!} \implies \mathbf{f^{(11)}(0) = -\frac{11!}{3!} = -\frac{11!}{6} = -6\,652\,800}\) // Igualando f^(11)(0)/11! a -1/3!, isolamos f^(11)(0) = -11!/6 (na prova você pode deixar indicado como -11!/3! ou -11!/6!).
✅ Resposta Q5(b): \(f(x) = \sum_{n=0}^{\infty} \frac{(-1)^n}{n!} x^{3n+2}\) (\(R = \infty\)) e \(f^{(11)}(0) = -\frac{11!}{3!} = -\frac{11!}{6}\).
