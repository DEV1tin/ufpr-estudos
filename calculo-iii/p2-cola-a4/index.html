1. Teoria & WronskianoLista 4
Forma Canônica: $y'' + p(x)y' + q(x)y = g(x)$.
T.E.U.: Se $p, q, g$ contínuos em $I \ni x_0 \implies$ solução única em $I$.
Wronskiano: $W(y_1, y_2)(x) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_2 y_1'$
• Se $W(x_0) \neq 0 \iff \{y_1, y_2\}$ é L.I. (Base Fundamental).
Fórmula de Abel: $W(x) = C\, e^{-\int p(x)\,dx}$   ($C = W(x_0)$).
2. Coef. Constantes: $a y'' + b y' + c y = 0$
Eq. Característica: $a r^2 + b r + c = 0$,   $\Delta = b^2 - 4ac$.
$\Delta$RaízesSolução Geral $y_h(x)$
$\Delta > 0$$r_1 \neq r_2$ reais$c_1 e^{r_1 x} + c_2 e^{r_2 x}$
$\Delta = 0$$r_1 = r_2 = r$$(c_1 + c_2 x) e^{r x}$
$\Delta < 0$$r = \alpha \pm i\beta$$e^{\alpha x}(c_1 \cos\beta x + c_2 \sin\beta x)$
$\alpha = -b/(2a)$, $\beta = \sqrt{4ac - b^2}/(2a)$. Euler: $e^{i\theta} = \cos\theta + i\sin\theta$.
3. Redução de Ordem ($y_1$ conhecido)
Põe $y_2(x) = v(x) y_1(x) \implies$ recai em $w = v'$ de 1ª ordem:
$v'(x) = \dfrac{e^{-\int p(x)\,dx}}{[y_1(x)]^2} \implies y_2(x) = y_1(x) \displaystyle\int \dfrac{e^{-\int p(x)\,dx}}{[y_1(x)]^2}\,dx$
4. Não Homogênea: $y = y_h + y_p$
1) Coeficientes a Determinar (MCD):
• $P_n(x) \implies A_n x^n + \dots + A_1 x + A_0$
• $e^{\gamma x} \implies A e^{\gamma x}$  |  $\cos(\omega x), \sin(\omega x) \implies A\cos\omega x + B\sin\omega x$
• $e^{\gamma x}\cos\omega x \implies e^{\gamma x}(A\cos\omega x + B\sin\omega x)$
Regra do $x^s$: Se algum termo de $y_p$ coincide com $y_h$, multiplique por $x$ ($s=1$) ou $x^2$ ($s=2$ se raiz dupla).
2) Variação dos Parâmetros (MVP) – Universal:
Atenção: Dividir pelo coeficiente líder de $y''$ antes de achar $g(x)$!
$y_p(x) = u_1(x) y_1(x) + u_2(x) y_2(x)$, onde:
$u_1'(x) = -\dfrac{y_2(x) g(x)}{W(y_1, y_2)}, \quad u_2'(x) = \dfrac{y_1(x) g(x)}{W(y_1, y_2)}$
Obrigatório para $\tan x, \sec x, \ln x, 1/x, \sqrt{x}$.
5. Equações de Cauchy-Euler ($x > 0$)
Forma: $a x^2 y'' + b x y' + c y = g(x)$. Ensaio: $y = x^r$.
Eq. Indicial: $a r(r-1) + b r + c = 0 \iff a r^2 + (b-a)r + c = 0$
• $r_1 \neq r_2$ reais: $y_h = c_1 x^{r_1} + c_2 x^{r_2}$
• $r_1 = r_2 = r$: $y_h = (c_1 + c_2 \ln x) x^r$
• $\alpha \pm i\beta$: $y_h = x^\alpha [c_1 \cos(\beta \ln x) + c_2 \sin(\beta \ln x)]$
MVP em Cauchy: divida por $ax^2 \implies g_{can}(x) = \frac{g(x)}{ax^2}$.
6. Oscilações Mecânicas: ModeloLista 5
$m x''(t) + c x'(t) + k x(t) = F(t)$
• Equilíbrio Estático: $m g = k \Delta l \implies k = mg / \Delta l$.
• Freq. Natural: $\omega_0 = \sqrt{k/m}$  |  Amortecimento: $\gamma = \dfrac{c}{2m}$.
• Eq. Característica: $m r^2 + c r + k = 0 \implies \Delta = c^2 - 4mk$.
• Amortecedor Crítico: $c_{crit} = 2\sqrt{km} = 2m\omega_0$.
7. Movimento Harmônico Simples ($c=0, F=0$)
$x''(t) + \omega_0^2 x(t) = 0 \implies x(t) = c_1\cos(\omega_0 t) + c_2\sin(\omega_0 t)$
Forma Amplitude-Fase: $x(t) = A \cos(\omega_0 t - \phi)$
• C.I.: $c_1 = x_0$  |  $c_2 = v_0 / \omega_0$.
• Amplitude: $A = \sqrt{c_1^2 + c_2^2} = \sqrt{x_0^2 + (v_0/\omega_0)^2}$
• Fase $\phi$: $\tan\phi = c_2 / c_1 = v_0 / (\omega_0 x_0)$ (analisar quadrante!).
• Período: $T = \dfrac{2\pi}{\omega_0}$  |  Frequência: $f = \dfrac{1}{T} = \dfrac{\omega_0}{2\pi}$.
8. Vibrações Livres Amortecidas ($c>0, F=0$)
A) Subamortecido ($\Delta < 0 \iff c < 2\sqrt{mk}$):
Raízes: $r = -\gamma \pm i \omega_d$, quase-frequência de oscilação:
$\omega_d = \sqrt{\omega_0^2 - \gamma^2} = \sqrt{\dfrac{k}{m} - \left(\dfrac{c}{2m}\right)^2}$
$x(t) = A e^{-\gamma t} \cos(\omega_d t - \phi), \quad T_d = \dfrac{2\pi}{\omega_d}$
• Decr. Logarítmico: $\delta = \ln\left(\frac{x(t)}{x(t+T_d)}\right) = \gamma T_d = \dfrac{2\pi \gamma}{\omega_d}$.
B) Amortecimento Crítico ($\Delta = 0 \iff c = 2\sqrt{mk}$):
$x(t) = (c_1 + c_2 t) e^{-\gamma t}$
Retorno mais rápido ao repouso SEM oscilar (passa por $x=0$ no máx 1 vez).
C) Superamortecido ($\Delta > 0 \iff c > 2\sqrt{mk}$):
$x(t) = c_1 e^{r_1 t} + c_2 e^{r_2 t} \quad (r_1, r_2 < 0 \text{ reais distintos})$
Movimento aperiódico e muito viscoso (retorno lento ao zero).
9. Vibrações Forçadas: $F(t) = F_0 \cos(\Omega t)$
1) Sem amortecimento ($c = 0$):
• Se $\Omega \neq \omega_0$: $x_p(t) = \dfrac{F_0}{m(\omega_0^2 - \Omega^2)} \cos(\Omega t)$.
Se $\Omega \approx \omega_0 \implies$ Batimentos (Beats): amplitude modulada.
• Se $\Omega = \omega_0 \implies$ Ressonância Pura:
$x_p(t) = \dfrac{F_0}{2m\omega_0} t \sin(\omega_0 t) \implies \text{Amplitude cresce } \propto t$
2) Com amortecimento ($c > 0$):
$x(t) = x_{trans}(t) + x_{perm}(t)$, com $x_{trans} \to 0$ quando $t \to \infty$.
• Permanente: $x_p(t) = A_s \cos(\Omega t - \delta)$,   com:
$A_s = \dfrac{F_0}{\sqrt{m^2(\omega_0^2 - \Omega^2)^2 + c^2\Omega^2}}, \quad \tan\delta = \dfrac{c\Omega}{m(\omega_0^2 - \Omega^2)}$.
• Freq. Ressonância Amortecida: $\Omega_R = \sqrt{\omega_0^2 - 2\gamma^2}$.
9.1 Analogia: Circuitos Elétricos RLC
$L Q''(t) + R Q'(t) + \frac{1}{C} Q(t) = E(t)$   ou   $L I'' + R I' + \frac{1}{C} I = E'(t)$
$m \leftrightarrow L$ (indutância)  |  $c \leftrightarrow R$ (resistência)  |  $k \leftrightarrow 1/C$ (inverso da capacitância)
$x(t) \leftrightarrow Q(t)$ (carga)  |  $x'(t) \leftrightarrow I(t)$ (corrente)  |  $F(t) \leftrightarrow E(t)$ (fem da fonte).

11. Séries de Potências & Raio
Raio $R$: $\sum_{n=0}^\infty c_n (x - x_0)^n \implies R = \lim \left|\dfrac{c_n}{c_{n+1}}\right| = \dfrac{1}{\lim \sqrt[n]{|c_n|}}$.
Intervalo $I$: $(x_0-R, x_0+R)$ + testar os extremos $x_0 \pm R$ individualmente!
Operações: Pode derivar e integrar termo a termo dentro de $(-R, R)$.
12. Séries de Taylor & Maclaurin ($x_0=0$)
$\frac{1}{1-x} = \sum_{n=0}^\infty x^n \;\; (|x|<1) \quad|\quad e^x = \sum_{n=0}^\infty \frac{x^n}{n!} \;\; (\forall x)$
$\cos x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n}}{(2n)!} \quad|\quad \sin x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{(2n+1)!}$
$\ln(1+x) = \sum_{n=1}^\infty (-1)^{n-1} \frac{x^n}{n} \;\; (-1 < x \le 1)$
$\arctan x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{2n+1} \;\; (|x| \le 1)$
$(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \dots \;\; (|x|<1)$
13. Integrais & Derivadas Essenciais
$\int \tan x \,dx = \ln|\sec x| \quad|\quad \int \cot x \,dx = \ln|\sin x|$
$\int \sec x \,dx = \ln|\sec x + \tan x| \quad|\quad \int \csc x \,dx = -\ln|\csc x + \cot x|$
$\int \sec^3 x \,dx = \frac{1}{2}(\sec x \tan x + \ln|\sec x + \tan x|)$
$\int \frac{dx}{x^2+a^2} = \frac{1}{a}\arctan\left(\frac{x}{a}\right) \quad|\quad \int \frac{dx}{x^2-a^2} = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right|$
$\int \ln x \,dx = x\ln x - x \quad|\quad \int u\,dv = uv - \int v\,du \text{ (LIATE)}$
